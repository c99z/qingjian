## 开关

默认开启。Linux 在「设置 → 通用 → 拼音自动纠错」可开启或关闭，点击「应用」保存，正在输入的一轮结束后生效。
也可在配置文件 `[general]` 中设置 `pinyin_correction = true` 或 `false`；三个平台共用此项，目前图形开关在 Linux。

关闭后不再修正拼音或补入敲错候选，本地模型的自由生成兜底也停用；正常词库候选和整句排序继续工作。云端词只接受与输入相符的读音，主动用 Tab 接受的云整句补全仍可使用。
模糊音、英文模式的拼写建议独立控制。

## 两种纠错

- **拼音无法完整切分时**（多输、少输、颠倒、输错一个字母）：`nihooma` → 你好吗，`woxiagnqu` → 我想去，`mingtain` → 明天。
  拼音行将被改动的字母以删除线标出并保留原位，候选全部按纠正后的拼音给出。
  相邻两键颠倒时不必等整个词输完：`mignt`、`migntia` 就已按 `ming't`、`ming'tia` 给出 明天，继续输入即可；
  两种纠正都说得通时优先按颠倒解释（`mignti` → 命题，而不是改一个字母的 面体）。
- **每个音节合法、整句不通顺时**：`meiganxi` 同样可出「没关系」（`gan` 视为 `guan`）。此类纠错只影响整句，不影响单个词的候选。

只有纠正后的句子明显比原样通顺时才纠正；合法简拼（如 `nhao`、`womend`）优先保留。中英混输时，整段为英文词的输入（`hello`）不纠正；专注中文时仍按拼音判断。

简拼已能匹配整段输入中的中文词时，不再触发额外的模型生成。例如 `houxuanc` 可匹配「候选词」，不会因后台生成了「候选C」而把它挤到首位。

完整拼音能匹配到一个词时，该词也会参与和整句的比较；不会仅因为另一条候选是整句，就自动把它排到这个词前面。选词记录会帮助排序，合理的整句仍可成为首选。
整词排在前面时，其他整句仍可改选。随包词库也补充了「内卷」「靠谱」「显眼包」「异步」等常用表达，无需另行导入词库。

## 结合语境排序

有充分词频和上下文依据的纠正，不会只因后台模型更偏向原字母读音就轻易被挤掉。例如 `meiganxi` 可将「没关系」排在首位，同时保留「没敢洗」供改选。
应用能提供光标前文时使用该前文，否则参考最近上屏的词；句末标点会断开语境。选词习惯仍参与排序，原样读法更合适时也能排第一。

纠错并不保证每次猜中本意，多处错误或歧义很大的输入仍可能需要改选或修改拼音。

原拼音对应的整句会独立参与比较，不会因纠错候选较多而被提前挤掉。例如 `zhideshi` 的「指的是」仍能正常参与排序，不会只剩改成 `shi de shi` 的候选。

## 不需要纠正时

`Enter` 仍将所敲字母原样上屏。拼音行显示整段拼写纠正时，按回车原样上屏一次，此后不再纠正该字母串。

## 记忆习惯性错误

被接受的纠正会被记录：习惯将 `shuo` 输成 `shou` 的用户，几次之后「我说」会自然排到前面。用 `Backspace` 删除后改选会一并撤销该记录。

双拼下不启用拼写纠错：输错一个键改变的是整个声母或韵母，单处编辑的模型不适用。五笔（形码）下同样不启用——敲的是字根编码，不是拼音。
