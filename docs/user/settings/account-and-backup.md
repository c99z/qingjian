Linux 的日常输入无需登录。本机青简服务保存学习记录和统计，设置窗口关闭后仍可继续输入。

## 本机备份与恢复

在「青简设置 → 备份与恢复」导出 `.qjb` 备份，或选择备份文件恢复。需要新版青简本机服务正在运行。

备份包含已保存的配置、短语、学习记录、统计、个人释义、用户词库和青简定制主题文件。不含 AI 密钥、账号凭据、输入日志、运行日志和大型模型。备份文件本身没有密码加密；请保存在自己信任的位置。用户数据最多 64 MiB。

恢复前先应用或撤销未保存的设置，并完成所有窗口里尚未上屏的输入。恢复会替换本机数据，自动保留恢复前备份到学习数据目录的 `backups` 中；文件有损坏或不支持的版本时拒绝恢复。恢复后自动重新读取设置，云联想保持关闭，本机已有 AI 密钥保留。Fcitx5 的全局主题选择和字体设置不会随备份改变。

## 登录自建服务

在「账号与同步」填写自己部署的账号服务 URL、用户名和密码，点击「注册」或「登录」。账号服务地址与「云服务」页的 AI API URL 独立。

远程地址需要 HTTPS。本机测试可以用 `http://127.0.0.1:9080`。注册需要服务管理员先开放注册；用户名接受 3–64 个字母、数字或 `_ - . @`，密码至少 12 字节。成功后密码输入框会清空，本机只保存登录会话。会话到期后重新登录；「退出登录」清除本机凭据并尝试注销远程会话。

## 在设备间同步

先在第一台设备应用设置，然后点击「上传备份」。在第二台设备登录同一个账号，点击「下载并恢复」。上传和恢复都需要各自的本机青简服务运行。

目前同步由你主动触发，上传整份快照、下载后替换本机数据，不自动合并两台设备的记录。如果其他设备已经更新云端快照，过期的上传会被拒绝，先下载核对再决定如何处理。本机保留上传时和恢复前的备份；云端只保留最新快照。

只有主动上传的数据会发送到你填写的账号服务。AI 密钥、账号凭据和输入日志不会进入快照。账号服务尚未提供自助密码找回和账号删除入口。
