- **macOS**：从输入法菜单打开（菜单栏「中 / 英」状态项，或系统输入源菜单中青简的几项），名为「偏好设置」。
- **Windows**：开始菜单的「青简设置」，或悬浮状态条上的 ⚙，名为「设置」。
- **Linux 开发版**：运行 `qingjian-linux-settings`。源码完整安装默认包含设置程序，也可从桌面菜单打开，见 [Linux](../getting-started/linux.md)。

macOS 与 Windows 的常规设置修改即时生效；自定义短语的启用开关即时生效，新增或编辑在点击「保存规则」后生效。

## 中文输入策略

Linux 的「通用 → 中文输入策略」可选择「专注中文」或「中英混输」。专注中文关闭自动英文候选、补全和拼接，并过滤模型生成的夹英文结果；需要英文时可主动切换到英文模式。中英混输沿用原有行为，可配合「中文优先」。旧配置默认中英混输。

三个平台也都可在 `[general]` 设置 `chinese_input_style = "chinese"` 或 `"mixed"`。与「英文模式给候选」是独立设置，详见 [英文模式](../input/english-mode.md#中文输入策略)。

## Linux 设置窗口（开发版）

修改先留在草稿中，点击「应用」或按 `Ctrl + S` 统一保存。「撤销修改」放弃尚未保存的修改；关闭窗口时会询问保存、放弃或返回。
通用、快捷键、本地模型和学习开关等设置保存到配置文件；正在输入时，相关设置等这一轮输入结束后生效。
「快捷键 → 中英切换」控制青简内部的中文 / 英文候选模式。若使用 Fcitx5 的 `Shift` 切换到键盘直接输入字母，
青简可只勾选 `Ctrl + Alt + Space`，保留两种切换方式；Fcitx5 的键盘模式不会显示青简候选。
服务未运行时仍可保存，窗口提示「下次启动生效」。配置文件损坏或同一项被其他程序修改时，窗口会说明原因并保留草稿。

「候选与外观」可以修改横竖排、字体、字号、常规或粗体、主题、中文与释义的普通和高亮颜色，以及释义字号比例。
「候选排列」选择「竖排」时，每行显示一个候选，释义在右侧；选择「横排」时，候选从左到右排列，每个候选中文在上、释义在下，缺释义处留白。整页没有释义时只显示一行。
Linux 横排的中文与释义共用候选字号、字重和颜色；单独的释义颜色与字号比例用于竖排。
竖排选择「与中文同字号」使释义与中文使用相同字号和字重。默认保持现有主题；选择浅色或深色预设后固定使用所选外观。
只选择现有主题时不会修改它；自定义颜色或字号比例会生成「青简定制」主题，原主题及其图片资源保留。

这些外观设置作用于 Fcitx5 经典面板，也会影响使用该面板的其他输入法；如果桌面使用其他候选面板，窗口会提示适用范围。
预览仅表示草稿效果，应用后可在页底的实际输入框检查真实候选面板。
Fcitx5 未运行时，外观修改会留在草稿中，其他青简设置可以保存；应用失败时窗口分别显示原因，不会把部分成功显示为全部生效。
外观与外部修改冲突时，可以先撤销草稿，重新检测后再编辑。

「统计」页显示今日、最近七天、累计输入量与当前辅助语言的词汇记录。服务未运行时显示已保存的数据和更新时间。
「学习与数据」页可以查看数据位置和修改学习、日志开关。「清空输入日志」确认后立即执行，需要青简服务运行，不需要再点击「应用」；当前输入、学习数据和统计保留。

「词库」页提供随包与用户词库开关、导入和移除；「短语」页新增、编辑、停用或删除短语，点「应用」统一保存。
「云服务」页提供 AI API URL、模型、API Key、候选格数、整句补全与测试连接。密钥仅在本机保存，测试使用当前草稿，不保存配置。
「备份与恢复」和「账号与同步」提供本机数据维护及自建账号服务登录，详见 [账号、备份与同步](account-and-backup.md)。

### 繁体输出

打开「繁体输出」后，候选与上屏文字按 OpenCC 转成繁体（只换字形，不换用语：软件 → 軟件）。云端词与整句补全同样转换。引擎内部仍按简体处理：用户词、词频、输入统计与输入日志都记简体，译词照常显示。

## 横排与拼音位置

macOS 与 Windows 竖排候选窗口在光标下方显示时，候选从上往下排列。若屏幕底部空间不足，窗口移到光标上方，候选从下往上按 1、2、3… 排列，首选词与拼音行靠近输入位置，页码移到顶部。数字键仍选择对应序号的候选。

macOS 与 Windows 横排时候选排成一行，仅高亮候选在下方单独一行显示译词，页码在行尾。Linux 横排每个候选的译词显示在对应中文下方。
macOS 上可以把这一行展开成多行：先在「候选窗口」页的排布下面勾选「横排时 ↑ / ↓ 展开成多行」（缺省不勾，不勾时横排下的按键与以前一样：
`↑` / `↓` 逐个移动高亮，`←` / `→` 移动拼音光标，`Esc` 清空）。勾选后立即生效：
按 `↑` / `↓` 会把这一行展开成 6 行的矩阵（一行对应一页候选），同时换到上一行或下一行；`←` / `→` 改为在候选之间移动（没展开时也是，拼音光标改用 `⌥ + ←` / `⌥ + →`），
数字键选的是高亮所在那一行的第几个，高亮移出矩阵上下边缘时按行滚动，翻页键一次翻一屏。展开后窗口大小在这一轮输入里保持不变；超过四个字的候选在格子里截断显示为「…」，
高亮到它时矩阵下方给出完整内容。继续输入拼音或按 `Esc` 收回单行。
「只在窗口」显示拼音适用于终端与部分 Electron 应用，这类应用对行内拼音的渲染效果较差。

## 输入法菜单（macOS）

云联想开关、模糊音子菜单、偏好设置、打开日志目录、版本号。配置文件解析失败时增加一条灰色的错误说明，此时沿用上一份可用的配置，输入法不退出。

## 直接修改配置文件

全部设置保存在一个配置文件中，「高级」页有「在编辑器中打开配置文件」，文件内每一项均附说明。保存后一秒内生效，无需重新切换输入法。

## 自定义短语（macOS）

「自定义短语」页以常驻表格显示启用状态、内容和固定候选位置，可直接勾选启用或停用。点击「+」新增，双击已有行或点击「编辑…」修改，选中后点击「−」删除。新增或编辑时，填写 1–32 个小写英文字母的输入码、1–9 的候选位置和文本，点击「保存规则」。文本可以包含空格、换行、地址、长回复或标点，按原样输出；候选窗口只展示长文本的简短预览。

例如将 `ee` 的第 1 位设置为 `：`，第 2 位设置为 `；`，输入 `ee` 后按空格选择首项，按 2 选择第二项。普通拼音候选填入其他位置，学习与模型重排不会改变自定义位置；云端词只使用不影响固定位置的剩余格。若固定位置超过第一页容量（例如第 9 位、每页 5 项），本次查询不显示云端词。位置跨页时按当前页的序号选择。

同一个输入码的位置不能重复，新增和编辑冲突时提示并拒绝保存；停用规则也保留其位置。没有足够普通候选时保留空位，空位不能上屏。选择已有规则后可编辑、停用或删除。

编辑期间若规则被其他窗口或外部文件修改，保存会提示并保留草稿，不覆盖新规则。保存会保留现有短语条目的注释。

默认中文标点模式会保存，重启后仍生效；选择半角不会改变自定义短语中的全角标点。英文模式不触发自定义短语。

### 系统的文本替换

「自定义短语」页勾选「也使用系统设置『键盘 → 文本替换』里的条目」（缺省勾选）后，系统文本替换中的条目在输入拼音时同样可用：
输入码敲全后短语出现在该输入码最靠前的空位（页里的规则优先占位），`Space` 或数字键上屏。
只有输入码全为小写英文字母的条目可用；系统设置中新增或修改的条目在下次切换到青简时生效。它们不在页里的表格中列出，要改请到系统设置。
