青简会结合前面刚输入的词、长期使用习惯和最近的选择调整中文候选。
同一段拼音下，最近选过的词会获得更多优先机会；旧的累计次数不会把一个词永久固定在首位。
例如「再／在」会参考前面的词，也会逐步跟随你最近的改选。
本地模型重排整句时也会参考同一段拼音下的选择。例如经常选择「录包」后，输入 `lubao` 时它可以排在模型拼出的「陆爆」前面。

这些习惯保存在本机，重启后仍然保留。关闭「学习输入习惯」或在私密输入框中打字时，不记录新的选择。
刚上屏的词用普通退格完整删掉后，重打同一段拼音并选择另一个词，会撤回误选那一次的学习，并记住后来的选择。
例如输入 `zai` 选了「再」，按一次退格删掉，再输入 `zai` 选「在」，刚才「再」增加的次数和最近选择偏好会撤回。
Linux（Fcitx5）也支持这个行为；编辑尚未上屏的拼音、只删除词中的部分文字不算撤回。
用方向键等导航键移动光标，或使用剪切、成段删除等快捷键后，不再把接下来的退格当作刚才的误选纠正。
删除后换一段拼音重新输入，目前不会自动建立新的拼音纠错规则。

如果个人词表里曾误记了整段拼音，它不会再挤占中文候选的位置；英文模式仍可以找到它。
确实需要作为英文使用的词，在英文模式选中一次候选后，也可以继续用于中英混输。
