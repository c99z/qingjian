# 候选质量：完整词竞争与人工补词

2026-10-16。第一轮处理词库缺词、整词被搜索裁剪漏掉后整句直接置顶的问题；不引入第三方输入法词库。

## 改动

- `query::competition` 将词级排序中首条完整拼音匹配词补为单词路径，使用与 Viterbi 相同的句首静态评分、个人插值和封顶用户加分，并参与同输入条件下的神经重排。只有实际漏掉该文本时才补，不改变原有路径去重规则。
- 补回整词胜出时，`SentenceBatch` 将原整句放在它后面；不删除原候选，否则回放中上屏学习会因候选消失而改变。一次改选只参与评分，不把整词强制钉在整句之前。
- `modern_words.tsv` 独立编写 15 个常用词与完整读音，初始化权重统一为 100（现有常用词底值上限），不是从雾凇复制的词频，也不是语料计数。
- `dict-convert supplement` 同时更新词库与 LM：已有字词频率不覆盖，未收录词面增加一元先验，不编造二元接续。原始语料未在本机，因此本轮没有重新训练 LM 或神经模型。坏输入拒绝，重复执行不重复加权，来源与补词许可写进 `.qj`。

## 验证

冷启动组启用含章·通变、基础词库与默认成语词库，不给个人数据、上文或云服务；按目标文本完整相等统计。技术文本拼音来自此前的青简冻结集，不代表通用输入准确率。

| 数据集 | 修改前首选 | 修改后首选 | 修改前前五 | 修改后前五 |
|---|---:|---:|---:|---:|
| 100 条人工诊断 | 84 | 88 | 92 | 99 |
| 既有 512 条技术文本 | 173 | 173 | 187 | 187 |
| 与前 512 条不重叠的 1,024 条技术文本 | 329 | 329 | 371 | 371 |

诊断集在 `assets/sample/candidate-quality.jsonl`；两个儿化简写 `daihuir` / `yihuir` 特意保留原输入，完整拼音 `daihuier` / `yihuier` 两边均可首选命中，不能将简写未命中记作词库错音。该集参与了问题定位，改进不能作为独立泛化收益；额外 1,024 条按 `SHA256(text)` 排序选取，排除既有 512 条，在改数据前冻结。

真实日志回放独立在内存中学习，不写个人数据，不启用神经模型或云端，共 16,657 条可评上屏。词级首选 13,228 → 13,233 / 14,684；整句 930 → 927 / 1,802；英文 157 / 167 不变。前五句子覆盖不变，词级候选缺失 169 → 164。三条原先选择的短句退到完整词之后，仍可改选；这轮长句准确率没有提升。

单元测试覆盖整词被跨度裁剪、整句评分更高时仍领先、同步与异步模型看到补回词、用户选择不会强制置顶、整句仍保留，以及补词幂等性、已有计数保留和坏输入保护。

## 复现

先备份现有 `data/generated/dict.qj` 与 `lm.qj`，生成命令见 `assets/lexicon/QINGJIAN.md` 最后一步。默认输出同时更新两个 `.qj` 和 `dict.tsv`，也可用 `--out-dir` 在独立目录生成。

```bash
cargo run --release -p qingjian-dict-convert -- supplement
cargo run --release -p qingjian-cli -- \
  --eval-cold assets/sample/candidate-quality.jsonl \
  --cold-output /tmp/candidate-quality-new.jsonl \
  --extra-dict data/generated/dicts/idioms.qj \
  --neural data/models/hanzhang-tongbian/hanzhang-tongbian-small.qjm
```

`--cold-output` 拒绝覆盖文件。完整本机验证结果与修改前的数据备份在 `/tmp/qingjian-update-20261016/`，其中个人日志只在本机临时目录，不进仓库。
