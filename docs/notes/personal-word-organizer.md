# 夜间个人词库整理验证记录

2026-11-09，Linux 开发实现。发行默认关闭；本机按用户要求安装并启用，每天 03:00（Asia/Shanghai）执行，沿用已有 API 配置。云联想与实验性语境排序仍关闭。

实现范围：复用云服务 API 配置与本机凭据，但与云联想开关独立。设置位于「学习与数据」，提供开关、小时、分钟及专业领域提示。后台按本机时间调度，默认 03:00；每天最多尝试一次，指定时刻后当日四小时内补做，需要电脑与 Server 运行。

整理只发送本地筛选的重复词证据：最近 14 天、日志尾部最多 4 MiB、2–8 个汉字、完整对齐读音、至少三次且跨两天。先排除基础库已有读音，再取最多 60 条，防止高频常用词占满新词额度；没有有效新词时不调用接口。模型只能选择编号并提供领域摘要，不能生成词或词频。新词静态权重不超过 30。原有学习器继续决定个人选择偏好。

本次结果替换独立的 `dicts/personal-agent.tsv` 快照，上一次保存到 `organizer/previous.tsv`。成功生成后等待所有输入会话的组句结束再加载；配置、授权或凭据变化、清日志、恢复备份取消旧结果。关闭任务保留已有词库，用户可在词库页停用。

## 未验证与限制

- 实际 API 固定文本连接测试成功，未使用真实私人日志调用外部 API，尚无真实服务的筛词质量评估，也未观察实际过夜调度；时间窗口由确定性测试覆盖。
- 第一版以实际输入证据为限，不主动下载专业词库，不批量补入尚未使用过的领域词，不训练本地模型，也不保证新词首选。
- 不自动唤醒关机或睡眠的电脑；超出当日补做窗口后等次日。
- 当前只实现 Linux 执行与设置；其他平台识别共享配置但不执行夜间任务。
- 只替换后台与设置程序，原子更新安装清单及整理配置；原程序、配置和学习数据已备份到用户数据目录 `backups/nightly-organizer-20261109-151546`。学习数据未用测试数据覆盖，插件与词库资源未替换；原 systemd 用户服务保持启用。已安装后台的私密测试会话查询 `sm`，首选为「什么」。
